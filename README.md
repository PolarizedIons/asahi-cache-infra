# Asahi-Cache Infra

This is the infrastructure repo for the [asahi-cache](https://github.com/PolarizedIons/asahi-cache) repo.

It deploys attic & hydra to build & cache the asahi-linux kernel for aarch64-linux from [here](https://github.com/nix-community/nixos-apple-silicon), aka. a cache for nix on Apple Silicon.

More information on how to consume it, is available on this [asahi-cache](https://github.com/PolarizedIons/asahi-cache) repo.
